# The 9-Layer Style DNA Framework

Analyze in this order. For each layer: observe → name it with precise vocabulary → decide DNA vs surface.

## 1. Lighting
- **Direction**: front / side (Rembrandt, split) / back (rim, silhouette) / top / under / ambient-shadowless
- **Quality**: hard (crisp shadows) / soft (wrapped) / mixed
- **Ratio**: high-key / low-key / balanced; contrast ratio feel (2:1 gentle → 8:1 dramatic)
- **Light color**: warm/cool/mixed-temperature (warm key + cool fill is a signature move, not a palette choice)
- **Behavior**: volumetric, bloom, flare, bounce, practicals visible?

## 2. Composition
- **Framing logic**: rule of thirds / centered-symmetric / golden ratio / deliberately unbalanced
- **Negative space**: generous / dense / weaponized (isolation)
- **Eye path**: where does the eye enter, travel, rest?
- **Depth strategy**: layered foreground-mid-back / flat-graphic / deep vanishing lines
- **Edges**: subjects contained or cropped aggressively?

## 3. Camera language
- **Focal feel**: wide (distortion, context) / normal / tele (compression, isolation) / macro
- **DOF**: razor-thin / moderate / deep focus
- **Angle**: eye-level / low (heroic) / high (vulnerable) / dutch (unease) / top-down (graphic)
- **Distance**: intimate close / conversational / observational / epic-remote

## 4. Rendering quality
- **Mode**: photographic / painterly / graphic-flat / 3D / mixed-media
- **Edge treatment**: crisp / soft / broken (dry brush, halation)
- **Detail distribution**: uniform / concentrated at focal point / deliberately sparse
- **Finish**: clean-polished / textured-organic / degraded (grain, noise, print artifacts)

## 5. Texture & materials
- Dominant surfaces: matte / gloss / metallic / fabric / skin treatment / weathering
- Grain: film grain, paper tooth, digital-clean
- Wear level: pristine / lived-in / decayed

## 6. Color RELATIONSHIPS (the critical layer)
Separate LOGIC (DNA — keep) from PALETTE (surface — swappable):
- **Contrast strategy**: complementary / analogous / monochrome+accent / triadic
- **Saturation hierarchy**: where is saturation allowed? (e.g., muted world + one saturated accent = DNA regardless of which hue)
- **Value structure**: dark-dominant, light-dominant, mid-heavy
- **Temperature play**: warm subject vs cool environment (or inverse)
- **Coverage ratios**: dominant/secondary/accent proportions (60/30/10 etc.)
The palette (actual hues) goes in DISCARD for TRANSLATE mode; the logic goes in KEEP.

## 7. Mood & emotional register
Two-word register: e.g. "melancholic-warm", "clinical-menacing", "playful-nostalgic". Note what CREATES it (usually a lighting+color+distance combination — name the combination).

## 8. Era / genre markers
- Period signals: film stock era, print process, fashion, architecture
- Genre grammar: noir, pastoral, cyberpunk, editorial, documentary, fairy-tale
- Flag which markers are load-bearing vs incidental

## 9. Subject treatment
- Stance toward subject: heroic / candid / clinical / tender / voyeuristic / iconic
- Human presence: portrait-dominant / figures-in-environment / absent (traces only)
- Styling consistency: how are subjects dressed/posed/groomed relative to the world?

## DNA vs Surface — the test

Ask: "If I changed this, would the style still be recognizable?"
- Changed and still recognizable → SURFACE (palette hues, specific subjects, specific locations)
- Changed and it collapses → DNA (lighting behavior, color logic, rendering, distance, mood machinery)

## Invariant threshold (EXTRACT mode)

Across a set: appears in ≥70% of images → DNA. 30-70% → tendency (note it). <30% → noise, ignore unless the user flags it.
